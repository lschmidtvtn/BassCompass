# BassCompass

Builds automated workflows for managing and tracking containerized applications on Linux systems for developers and system administrators.

BassCompass is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/BassCompass.git`
2. `cd BassCompass`
3. Install in editable mode: `pip install -e .`

## Configuration

BassCompass is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
